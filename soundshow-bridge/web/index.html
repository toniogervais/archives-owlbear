1 · Relier SoundShow

Colle le lien affiché dans SoundShow, par exemple http://192.168.1.20:8080/. L’adresse WebSocket est aussi acceptée.

2 · Choisir les fichiers à diffuser

Associe les boutons SoundShow aux vidéos de ton ordinateur. Seules les vidéos associées sont diffusées. Aucun fichier n’est envoyé dans un espace de stockage.

En attente d’une vidéo.

3 · Afficher les vidéos dans ta partie

Une seule connexion au début de la partie. Ensuite, lance tes vidéos normalement dans SoundShow : elles apparaissent dans une fenêtre des Archives ou d’Owlbear, sans recopier de code.
