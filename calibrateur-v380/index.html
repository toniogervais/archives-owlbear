Calibrateur V3.8

Ferme cette fenêtre. Dans la barre d'outils de la scène, choisis l'icône règle « Calibrateur V3.8 ».

Clique directement sur la carte : A, puis B. La ligne bleue indique la distance. Clique sur ✓ (ou Entrée) pour calibrer.

Flèches : déplace B de 0,1 px ; Maj + flèches : 1 px ; Alt + flèches : déplace A. Échap efface les repères. La carte et les tokens sont redimensionnés ensemble. Si une ancienne sauvegarde bloque le calibrage, clique sur ↻ « Repartir de la scène actuelle », puis reclique pour confirmer. Cela conserve exactement la scène actuelle mais abandonne l’ancienne annulation. Tu peux ensuite calibrer.
